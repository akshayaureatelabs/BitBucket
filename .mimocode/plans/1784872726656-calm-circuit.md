# UI Redesign Plan — AI Agent QA Dashboard

## Goal
Complete UI overhaul of the QA testing dashboard using **Neobrutalism** design language with **Indigo/Purple** palette, **collapsible sidebar**, and matching **Chrome extension popup** — **zero functional changes**.

---

## Design Direction: Neobrutalism

**Core Principles:**
- Bold, thick borders (2-3px solid black/dark)
- Vivid accent colors with high contrast
- Chunky shadows (offset, no blur — `4px 4px 0px`)
- Rounded corners (12-16px)
- Slightly tilted/rotated elements for playfulness
- Monospace accents for labels
- No glassmorphism/blur effects (replaced by solid fills + borders)

**Color Palette (Indigo/Purple Neobrutalist):**
- Background: `#F0EFFF` (soft lavender) / Dark: `#1A1625`
- Card BG: `#FFFFFF` / Dark: `#252037`
- Primary: `#6C5CE7` (vivid indigo)
- Accent: `#A29BFE` (light purple)
- Success: `#00B894`
- Danger: `#FF6B6B`
- Warning: `#FDCB6E`
- Borders: `#2D3436` (near-black) / Dark borders: `#3D3555`
- Text: `#2D3436` / Dark: `#F5F5F5`

## Implementation Steps

### Step 1: Redesign `ui/css/styles.css`

**Replace CSS variables:**
```css
:root {
  --bg-body: #F0EFFF;
  --bg-card: #FFFFFF;
  --bg-sidebar: #FFFFFF;
  --bg-input: #F8F7FF;
  --bg-hover: #E8E6FF;
  --border: #2D3436;
  --border-light: #636E72;
  --text: #2D3436;
  --text-dim: #636E72;
  --text-muted: #B2BEC3;
  --primary: #6C5CE7;
  --primary-light: #A29BFE;
  --success: #00B894;
  --danger: #FF6B6B;
  --warning: #FDCB6E;
  --adapted: #A29BFA;
  --shadow: 4px 4px 0px #2D3436;
  --shadow-lg: 6px 6px 0px #2D3436;
  --radius: 12px;
  --radius-lg: 16px;
}
```

**Key Component Changes:**
| Component | Current | New (Neobrutalist) |
|-----------|---------|---------------------|
| Cards | Glassmorphism, blur, semi-transparent | Solid white bg, 3px solid border, offset shadow |
| Buttons | Gradient bg, subtle shadow | Solid bg, 3px border, offset shadow, hover = shadow grows |
| Stat cards | Glassmorphism, top border accent | Solid bg, thick border, bold shadow, slight tilt on hover |
| Sidebar | Glass bg, blur backdrop | Solid white, thick right border, no blur |
| Topbar | Semi-transparent, blur | Solid bg, thick bottom border |
| Inputs | Thin border, subtle | Thick border, bold focus ring |
| Tables | Subtle rows | Alternating row bg, thick borders |
| Modals | Blur backdrop, slide-in | Solid overlay, thick border box, bounce-in |
| Toasts | Slide-in, solid color | Solid bg, thick border, offset shadow |
| Badges/Pills | Semi-transparent bg | Solid bg, thick border |

## Risk Mitigation

- **Class name conflicts:** Using existing class names, not adding new ones that JS references
- **CSS specificity:** Keeping specificity similar to current to avoid override issues
- **Dark/Light theme:** Both themes fully styled with neobrutalist variables
- **No JS changes:** Zero risk of functional regression
